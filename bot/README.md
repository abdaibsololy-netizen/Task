# PumpBot 🤖

بوت يقلّد نمط محفظة Pump.fun المرصودة في `master_wallet_*` — القواعد مستخرجة حرفياً
من البيانات (انظر `../analysis/STRATEGY_PATTERN.md`).

## النمط المُبرمَج

**دخول:** PumpSwap فقط | MCap $2–8K | Liq/MCap ≥ 85% | عمر 18–72 ساعة | 1.02 SOL ثابت | بدون DCA

**خروج:** الدراجة `50% @ x2 → 25% @ x3.5 → 25% @ x4.5 (trailing)` أو خروج كامل
`x1.15 بعد 8h` + وقف خسارة `x0.90` + إيقاف زمني `72h` + حماية rug (سقوط سيولة 50%)

## التركيب

```bash
cd bot
pip install -r requirements.txt
```

## التشغيل

```bash
# 1) اختبارات المنطق (بدون إنترنت)
python tests/test_strategy.py

# 2) اختبار رجعي على البيانات التاريخية
python backtest.py            # أو: python main.py --backtest

# 3) المحاكاة الحيّة (paper) — يراقب السوق الحقيقي ويتداول وهمياً
python main.py

# 4) التداول الحقيقي (⚠️ خطر!)
export PUMPBOT_PRIVATE_KEY="..."   # مفتاح محفظة صغيرة فقط!
MODE=live python main.py
```

## الملفات

| ملف | الدور |
|---|---|
| `config.yaml` | كل بارامتر — مرقّم بدليله في تقرير النمط |
| `strategy.py` | النواة: قواعد الدخول/الخروج (منطق نقي) |
| `scanner.py` | تدفق PumpPortal + بيانات العمر/السيولة |
| `executor.py` | تنفيذ paper / live |
| `portfolio.py` | المراكز + الحفظ + حدود المخاطر |
| `backtest.py` | مقارنة البوت مع أداء المتداول الحقيقي |
| `tests/test_strategy.py` | اختبار لكل قاعدة |

## ملاحظات أمان
- الوضع الافتراضي **paper** دائماً. لا تحوّل لـ live إلا بمحفظة تجريبية صغيرة.
- المفتاح يُقرأ من متغير البيئة فقط — لا يُكتب في أي ملف.
- البيانات التاريخية أداء سابق لا يضمن نتائج مستقبلية.
