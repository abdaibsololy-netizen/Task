# 📥 صندوق الإدخال | Inbox

> هنا تُحفظ **المواد الخام** قبل تصنيفها: أفكار، روابط، ملاحظات، اقتباسات، أرقام، أسئلة…
> Raw material lands here **before** classification. Nothing here reaches the manuscript directly.

---

## القاعدة | The rule

```
inbox/  →  (تصنيف + موافقة الباحثة)  →  الوجهة النهائية  →  inbox/processed/
```

**لا ينتقل شيء من هنا إلى `manuscript/` أو `sources.csv` إلا بعد موافقة صريحة.**
Nothing moves from here into the paper without explicit approval.

---

## قالب المادة الخام | Raw item template

انسخ هذا القالب إلى `inbox/YYYY-MM-DD-slug.md`:

```markdown
# <عنوان قصير>

- **التاريخ:** YYYY-MM-DD
- **المصدر:** (رابط / كتاب / محاضرة / فكرة شخصية / محادثة)
- **حالتي:** غير مصنّف | مصنّف | مدخل

## النص كما ورد
<النص الأصلي بدون تعديل — لا تعيد صياغته>

## ما فهمته منه
<بكلماتك>

## تصنيفي المقترح
النوع: مشكلة / حل / دليل / اقتباس / تجربة / هدف / فائدة / خطر / مساهمة
الوجهة المقترحة: <المسار>
```

---

## بعد المعالجة | After processing

1. تُنقل المادة إلى وجهتها (حسب `docs/07_intake_protocol.md`).
2. تُحفظ النسخة الأصلية في `inbox/processed/`.
3. يُسجَّل السطر في جدول «سجل الإضافات» داخل `docs/07_intake_protocol.md`.

---

## ⚠️ تنبيهات

- لا تكتبي أسماء أشخاص أو بيانات حساسة هنا إذا كان المستودع عاماً.
- الرابط أو الـDOI يكفي — ما نحتاج نسخة PDF داخل المستودع.
- إذا كانت المادة مجرد سؤال أو استفسار، فمكانها المحادثة لا المستودع.
